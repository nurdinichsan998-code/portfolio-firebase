Profil & foto

Nama, perkenalan, pendidikan, dan ringkasan profil.

Unggah memakai Firebase Storage (Blaze). Foto dipotong persegi dan diperkecil hingga 640 × 640 piksel. URL HTTPS dapat digunakan tanpa Storage.

Foto baru baru tampil di website setelah perubahan diterbitkan. Foto yang sudah terunggah bersifat publik; menghapusnya dari profil tidak menghapus arsip file di Storage.

Pengalaman kerja

Tambah, edit, hapus, atau ubah urutan. Baris teratas ditampilkan lebih dahulu.

Kontak

Kontak ini tampil publik. Form pengunjung tetap menyiapkan draf email, bukan mengirim otomatis.

Proyek & galeri

Tambah atau hapus proyek sesuai kebutuhan. Pilih kategori preset atau ketik kategori sendiri. Foto pertama menjadi thumbnail; Photography, 2D Design, dan Graphic Design tampil sebagai kolase dengan Lightbox.

Tidak ada batas jumlah proyek tetap. Semua metadata tetap mengikuti batas keamanan dokumen 150 KB. File gambar disimpan terpisah di Storage. Menghapus proyek atau URL tidak menghapus file Storage secara permanen.
